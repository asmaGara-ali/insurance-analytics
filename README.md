## 📊 Power BI Dashboard

The project also includes a Power BI dashboard designed to transform insurance data into interactive visual insights.

The dashboard aims to support the analysis of:

- **Insurance Portfolio:** Total policies, total premiums, and average premium.
- **Claims Analysis:** Claim volumes, claimed amounts, approved amounts, and paid amounts.
- **Customer Risk:** Customer distribution across risk bands.
- **Product Performance:** Premium contribution and comparisons across insurance products.
- **Portfolio Trends:** Monthly premium evolution over time.

## 🔍 Project Workflow

1. **Data Quality Assessment** — Identify missing values, duplicates, and potentially invalid records using SQL.
2. **Data Validation** — Check relationships between insurance tables and validate business rules.
3. **Data Analysis** — Answer business questions using SQL queries.
4. **Data Visualization** — Build an interactive Power BI dashboard to explore insurance KPIs and performance.
5. **Insights & Recommendations** — Interpret findings to support data-driven decisions.
